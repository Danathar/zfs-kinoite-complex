```bash
for n in $(gh pr list --repo Danathar/zfs-kinoite-complex --state all --limit 1000 --json number \
             -q '[.[] | select(.number <= 248) | .number] | sort | .[-40:] | .[]'); do
  inline=$(gh api "repos/Danathar/zfs-kinoite-complex/pulls/$n/comments" --paginate \
    -q '[.[] | select(.user.login | contains("codex"))] | length')
  body=$(gh api "repos/Danathar/zfs-kinoite-complex/pulls/$n/reviews" --paginate \
    -q '[.[] | select(.user.login | contains("codex")) | .body | scan("P[0-3] Badge")] | length')
  echo "#$n inline=$inline body=$body"
done
```

The loop counts findings posted inline and findings inside a review body,
using the `P0`–`P3` badge every Codex finding carries. None of the 40 review
bodies carried one, so the inline count is the total. The count says where
review found something, not whether the finding was right; `docs/metrics.md`
says what to do with a pull request that collected several.
